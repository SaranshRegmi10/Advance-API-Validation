1. Create a user (POST: api/users)

--what we send
{
    "name":"Saransh"
    "job":"QA Automation"
}
--what the server repsonds
{
    "name":"Saransh"
    "job":"QA Automation"
    "id":782
    "Created At":"2026-07-31T10:45:12.345Z"
}
